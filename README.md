# OMV Home

Interface web moderna (estilo ZimaOS) para o OpenMediaVault 7. Roda ao lado da UI original,
sem alterar o sistema. Containers viram "apps" na home, com loja de templates compose.

- Backend: Go (`backend/`) · Frontend: React + TypeScript (`frontend/`)
- Desenvolvimento guiado por specs: veja [`specs/`](specs/README.md)

Instruções de execução serão adicionadas junto da implementação.
